# 示例：13B 双转子平台的填表

这份是 `spec-template.md` 的填好版本，用来对照。

## 1. 产品

| 项 | 内容 |
| --- | --- |
| 产品名 | 13B 双转子平台 |
| 一句话定位 | 同等重量下功率密度最高的内燃机方案，适合无人机与增程动力 |
| 与谁竞争 | 四冲程活塞机、同排量转子方案、电动方案 |
| 报价区间 | 不便公开 |

## 2. 客户最常问的 5 个问题

1. 转子发动机的密封片是不是很容易坏？
2. 油耗是不是比活塞机高？
3. 你们和别家转子方案差在哪？
4. 坏了多久能修好，备件贵不贵？
5. 能不能按我的工况重新标定？

## 3. 五个卖点

| 技术点 | 客户语言 | 能证明它的画面 |
| --- | --- | --- |
| 三腔连续做功 | 输出平顺、振动小 | 切开 + 慢放，三腔同时处于不同冲程 |
| 无往复惯性力 | 能上高转速、功重比高 | 油门推到底，转速与功率同时上去 |
| 无配气机构 | 故障点少、好修 | 拆开，只有转子、偏心轴、缸体 |
| 体积小 | 整机布置灵活、能减重 | 侧视图 + 比例尺 |
| 密封片可单换 | 维保可预期、不大修 | 故障演示 + 一片恢复 |

## 4. 三个差异点

| 维度 | 我们 | 竞品 | 怎么演 |
| --- | --- | --- | --- |
| 结构 | 三个运动件，无凸轮轴/正时链 | 活塞机气门机构复杂 | 拆开数零件 |
| 数据 | 功重比高，高转速区功率不掉 | 同排量活塞机高转衰减 | 油门 0→100 看曲线 |
| 服务 | 密封片可单换，故障可预警 | 常见做法是换总成 | 故障 → 恢复 |

## 5. 五个角色

| 角色 | 他的 KPI | 他最怕什么 | 给他看哪 30 秒 |
| --- | --- | --- | --- |
| 使用 / 工艺 | 出勤率、任务完成率 | 空中停车 | 切开 + 慢放 |
| 设备 / 维修 | MTTR、备件成本 | 拆一次要返厂 | 拆开 + 故障 |
| 采购 | 单价、交付 | 被审计问住 | 参数联动 + 案例 |
| 财务 | TCO、折旧 | 隐性停机成本 | TCO 三行表 |
| 老板 | 项目风险 | 供应商跑路 | 故障 + 服务条款 |

1. 三角转子（三个顶角密封片）
2. 8 字缸体（型线）
3. 偏心轴（1:3 传动）
